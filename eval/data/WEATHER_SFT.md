# 山中・オフライン向けの降水荒天リスク学習データ

生成器: [util/make_weather_sft.py](../../util/make_weather_sft.py)。Python標準ライブラリのみで動作する。

## 学習形式

生成先は weather_sft。train/dev/test/extra の各 JSONL の1行が1会話。
`messages` に system/user/assistant を格納し、assistant の本文は
`weather_risk`（整数）と `reason`（文字列）の2項目だけのJSON。
`reason` は**過去の観測根拠とその気象学的な意味の短い要約**で、
気圧の上下動（5分ごとの変化のばらつき）を主指標とし、相対湿度・気温は補助として扱う。
ネット・雨雲レーダーの確認案内や定型の注意書きは教師出力に含めない。
学習時は assistant 部分だけを損失の対象にする。

- 荒天リスクの定義: `min(round(今後60分の合計降水量[mm] × 10), 100)`。
  0〜100の整数に丸める（例: 0.254mm → 3、5mm → 50、10mm以上 → 100）。
  これは降水量の指標であり、降水確率や雷・突風を含む総合危険度ではない。
- user: 地点、t0、過去の気温・湿度・現地気圧・5分気圧差。
- 時刻は -60,-55,…,-5 分の12点。観測のない t0 の値は補間しない。
- 気圧差は隣接する掲載観測の差。最初の1点は null。
- 教師側の正解: t0+1〜t0+60分の合計降水量から求めた荒天リスク。
  ちょうど1時間後の瞬間の天気ではない。最大5分雨量は急変例の選別用メタデータにのみ残す。
- 未来値、過去降水量、選別カテゴリは入力には含めない。
- 同順の metadata JSONL に元サンプルID、選別カテゴリ、特徴量、正解値を保存する。
  outcome に R60_mm と weather_risk を併記する。
- manifest に定義、地点別の候補数・採用数・除外数を保存する。
- manifest の primary_signal に主指標 `P_volatility_hPa`（過去55分の5分ごと気圧変化の
  標準偏差）の定義と判定帯（0.06 / 0.14 hPa）、検証AUCを記録する。
- manifest の train_tendencies に、学習年の有効な元CSV行についてカテゴリ別の
  気圧変動大の割合、高湿度割合、湿度上昇割合、平均気圧変動量・平均湿度変化を保存する。
  近接時刻を含む記述統計であり、独立イベント数、因果効果、予測確率を表さない。

## 急変の操作的定義と採用目標

これは防災上の警報基準や学習済み予測ルールではなく、学習例を選ぶための暫定閾値。

|カテゴリ|定義（先に一致したもの）|目標比率|
|---|---|---|
|sudden_onset|過去30分 ≤0.254mm、未来の最初の降水が30分以内、未来の最大5分 ≥1mm|25%|
|rapid_intensification|過去30分 >0.254mm、未来の最大5分 ≥1mm、過去直近5分より ≥1mm 増加|20%|
|rain_onset|過去30分 ≤0.254mm、未来60分 ≥0.5mm|15%|
|ongoing_rain|未来60分 ≥0.5mm|10%|
|light_rain|未来60分 >0mm、上の条件以外|5%|
|sensor_alert_no_rain|未来60分 =0mm かつ55分気圧差 ≤−1hPa、または最終RH ≥85%かつ55分RH差 ≥10ポイント|15%|
|dry|その他の記録雨量ゼロ例|10%|

気圧低下・湿度上昇でも降らない対照例も含め、「気圧低下＝雨」の誤学習を抑える。
そもそもこの粒度（1地点・1時間・分単位）では気圧の正味の上下の向きに予測力はなく、
荒天と関係するのは**気圧が細かく上下する変動の大きさ**である。sensor_alert_no_rain の
55分気圧差やRHの条件は、前兆らしく見えても降らない空振り例を集めるための選別条件に過ぎない。
気圧低下のある降雨だけを採ることはしない。前兆の乏しい急変も残す。
各層でハッシュに基づく再現可能な候補抽出を行い、同地点・同splitでt0を60分以上離す。
これは同じ雨雲による事例を完全に独立化する処理ではない。
希少層や間隔条件で不足する分は他層で補うため、比率は厳密には固定されない。
既定は各地点 train 600/dev 150/test 150/extra 60 件を上限とする。
CLI の各 split の per-station オプションで変更できる。
出力先が既に存在する場合は上書きせず停止する。再生成は --overwrite の明示時のみ許可する。

## 今回の生成結果と実測傾向

5地点で train 3,000件、dev 750件、test 750件、extra 300件、合計4,800件を生成。
train の急な降水開始666件と急な強まり447件は、合計1,113件（37.1%）。
センサー上の注意兆候があっても記録降水のない450件も含めた。

**主指標の検証**: 気圧変動 `P_volatility_hPa`（5分ごと気圧変化の標準偏差）は、
荒天（risk≥50）の識別でAUC≈0.75（test）と、相対湿度0.62や正味気圧変化0.42を上回る。
四分位で単調に荒天率が上がる（静穏 Q1 ≈3〜7% → 変動大 Q4 ≈35〜44%）。
一方、従来の「55分で1hPa以上の気圧低下」は降雨に対しAUC 0.37〜0.43と逆相関で、
この粒度では**気圧の下降そのものは荒天の兆候にならない**。対流性降水は中規模高気圧
（mesohigh）を伴い気圧が上がることも多く、±1hPa帯は日変化の大気潮汐に支配される。

学習年の欠測等を除いた元CSVの急な降水開始5,891行では、気圧変動が大（≥0.14hPa）の割合は
31.08%、最終RHが85%以上の割合は47.62%。急な強まり5,818行では気圧変動大51.07%、高湿度86.13%。
したがって、**単一の強い前兆だけに限定すると多くの急変例を取り逃がす**。
前兆を確実な予測規則として扱わず、急変例と空振り例の両方を残している。
これらは近接窓を含む行単位・重みなしの記述統計で、独立した現象数ではない。

## 品質・リーク・評価の注意

- 掲載するセンサー12点、過去30分の降水、未来60分の降水に欠測がある例は除外。
  元データの「欠測を0として危険度計算」とは異なり、教師雨量に欠測ゼロ補完を使わない。
- 年別splitを維持し、過去・未来の60分窓が年境界を跨ぐ例を除く。
- 高温多湿だけで対流不安定や雷を断定しない。現地気圧を海面気圧と混同しない。
  気圧の正味の上下の向き（上がった/下がった）だけでは荒天を判断せず、変動の大きさを見る。
- 元の降水量には雨雪の区別がないため、教師文は原則「降水」と表現する。
- 未来の観測値はリスクの教師値を作るためだけに使い、入力と理由文には含めない。
  理由を正解から逆算して作らないため、同じ過去観測なら未来の結果が異なっても理由は同じになる。
  理由文は数値リスクの根拠を厳密に証明するものではなく、観測上の兆候を記述する合成文である。
- この教師文はルールベースの合成文。物理法則から未来を計算した結果や、気象予報士が
  全件監修した文章ではない。学習前に急変例・空振り例を人手で確認すること。
- 用途はネット接続のない山中での簡易予測。学習元は米国空港の地上観測であり、
  山地での精度は未検証。現地気圧は標高・移動に伴う変化も含むため、運用時には
  同じ地点に設置したセンサーの履歴を使うか、標高変化を別途補正する必要がある。
  こうした運用上の説明はこの仕様書に集約し、毎回の教師出力には繰り返さない。
- 今回のdev/testも急変重点のチャレンジセット。自然頻度での性能や確率較正には使わない。
  元CSVのtestを用いた別評価で、急変再現率、見逃し率、誤警報率、リードタイムを確認する。
- 元のweightは元CSVでのdry間引き補正だけ。今回の追加抽出確率は補正しない。
- 2025年のextraは元アーカイブの欠測が多いため本評価と分ける。
- 元CSVもdryを間引いているため、本データは元の全時刻の完全な代表ではない。
